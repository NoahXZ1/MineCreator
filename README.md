# MineCreator

This is the repo of LLM-based AI design and building tool for Minecraft

面向 Minecraft 建筑创作的轻量 AI 设计工具。

用户与 LLM 讨论建筑需求、上传参考图、查看预览并修改设计，确认后在游戏中施工；将设计整理为可复用的建筑档案，便于下次生成同风格的变体。

## 项目初衷

在论文与申博之外，通过有趣、反馈直观的小项目调节节奏，同时积累 LLM agents、多模态交互、持久化、设计工具和游戏集成的工程经验。控制初版规模，优先做通完整体验。

## 核心体验

提出想法或加载建筑档案 → 对话设计 → 预览 → 修改并确认 → 游戏内施工 → 检查结果 → 保存档案。

- 对话设计：讨论风格、用途、尺寸、材料和参考图。
- 概念图预览：帮助确定风格、氛围和轮廓。
- 实际蓝图预览：呈现将要施工的方块结构；预览与施工使用同一份建筑数据。
- 建筑档案：保存描述、参考图及其用途、确定的偏好、可变条件和认可的历史版本。
- 局部修改：支持保留主体、仅修改屋顶等操作。
- 施工检查：读取游戏成品，验证是否符合确认的蓝图。

初版体验目标：围绕一座凉亭或小木屋，完成讨论、参考图、预览、一次修改、施工、保存档案和加载档案生成变体。

## 已确定与待确定的事项

- **已确定：使用 Minecraft Java Edition。** 用户已拥有微软官方正版 Java 版和基岩版。
- 当前倾向后端执行蓝图，具体接入方式尚未确定；玩家 bot 可作为未来的另一种执行方式。
- 施工中的常规操作交给程序执行，LLM 负责设计与必要的修改、检查，控制调用次数和 token 消耗。
- 前后端技术栈、模型供应商、Minecraft 具体版本和持久化格式尚未确定。

## 版本追踪与备份

个人参考文档及其生成脚本统一放在 `local-docs/`，仅保留在本地，不纳入 Git 追踪。

当前阶段为项目初始化，尚无功能实现。本地 Git 使用 `main` 分支，远程 `origin` 为 [NoahXZ1/MineCreator](https://github.com/NoahXZ1/MineCreator)。

### 工具分工

- Git：记录本地修改和可恢复的提交。
- GitHub：保存推送后的代码历史，并支持后续 issues 和 pull requests。
- Hugging Face：如需发布模型权重、数据集或在线演示，再引入。
- Docker：如需复现运行环境或简化部署，再引入；相关配置届时纳入 Git。

### 纳入 Git 的内容

代码、文档、依赖清单与锁文件、配置模板、测试，以及经过选择的小型建筑蓝图和示例素材。每完成一个有意义且可检查的改动，提交一次并及时推送。

```powershell
git status
git diff
git add <本次修改的文件>
git commit -m "Describe the change"
git push
```

### 另外备份的内容

API 密钥与登录凭据不提交。大型模型文件、依赖、构建产物与缓存不提交，优先通过依赖清单和来源记录恢复。

游戏世界、运行时数据、用户建筑档案、参考图片和生成结果需要独立的数据备份。预留 `runtime/` 与 `data/` 存放本地数据并忽略；实际存储位置、备份工具与周期待实现时确定。应在重大施工或迁移前保存一致的快照，并验证能够恢复。版本库不等于整个游戏与用户数据的备份。

只有成功推送的提交才有 GitHub 上的副本；当前尚未建立独立的数据备份任务。
